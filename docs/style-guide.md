# 時継舎 デザイン仕様

## 参照元

- 原本: `/home/yutaka/Share/EAI_Workspacetogitsugisha.png`
- 作業用コピー: `docs/reference-design.png`

## 全体コンセプト

- 日本の古物を静かに紹介する、落ち着いた藍染め風の世界観
- 生成りの和紙を思わせる背景に、水彩のにじみと手描き感を重ねる
- 高級感よりも、親しみと品のある端正さを優先する
- 年配者にも読みやすいよう、文字は大きめで行間に余裕を持たせる

## デザイン観察メモ

- 背景は全面が明るい生成り色で、紙の繊維感を感じるやわらかい質感
- 上部と左右に藍色の水彩にじみが入り、画面全体の余白が広い
- 主役は中央の大きな屋号と、左右に配置された古物イラスト
- 写真とイラストが混在しているが、全体は藍色で統一されている
- 下部に濃紺の帯と明るい本文領域があり、情報の切り替えが明確

## カラートーン

- 主色: 深い藍色、濃紺、墨に近い青
- 背景色: 生成り、和紙調の淡いクリーム色
- 補助色: やや灰みのある淡い青、水彩のにじみを感じる青
- 強調は彩度を上げず、濃淡差で見せる

## タイポグラフィ方針

- 屋号は和の空気感がある明朝体系を優先する
- 本文も可読性重視で明朝寄りを基本候補にする
- ナビゲーションや補助情報は細すぎない文字で安定させる
- 年配者向け配慮として、本文は小さくしすぎない

## 文字サイズの目安

- メインビジュアル屋号: 非常に大きく見せる
- セクション見出し: 十分に大きく、中央配置でも読めるサイズ
- 本文: PC でも余裕を持って読める大きさ
- ナビゲーション: 小さすぎる上品さより、見つけやすさを優先する

## レイアウト方針

- PC では横幅を広く使い、中央に主題を置く
- 余白を広めに取り、詰め込み感を出さない
- スマートフォンでは縦積みにして、見出し、本文、品情報を順に読める構成にする
- 各セクションは帯や背景色の切り替えで自然に区切る

## ホームページ構成方針

### 1. ヘッダー

- 左に屋号
- 右に主要ナビゲーション
- 現在ページが分かる下線表現を採用可能

### 2. メインビジュアル

- 中央に「とぎつぎしゃ」と「時継舎」を大きく表示
- キャッチコピーは短く、余白を活かして置く
- 左右に古物や植物のイラストを配置し、対称に近い安定感を持たせる

### 3. 品目導線

- 品目カテゴリを横並びで配置
- アイコンと文字を組み合わせ、直感的に選べるようにする
- 初期候補は古時計、器・陶磁器、古道具、古布・染織、その他

### 4. お知らせと新着の品

- 左にお知らせ欄、右に新着の品一覧の二段構成が原本に近い
- お知らせ欄は濃紺背景に白文字で視認性を確保
- 新着の品は写真カードを横並びにし、品名と価格を明瞭に表示

### 5. フッター

- 濃紺帯で締める
- 問い合わせ、方針、表記類のリンクを簡潔に並べる

## 画像方針

- イラストは藍染め風、水彩風、手描き感のある統一トーンに寄せる
- 写真を使う場合も、背景や色温度が浮かないよう調整前提で扱う
- 公開画像は `assets/images/` 配下に用途別に整理する
- 参考画像や検討資料は `docs/` に置き、公開素材と分離する

## UI 方針

- ボタンやリンクは細い線と余白で上品に見せる
- 装飾は多用せず、紙、藍色、余白、イラストで雰囲気を作る
- ホバーやタップ時の反応は控えめでよいが、状態変化は明確にする

## 実装上の注意

- まずは静的HTMLサイトとして成立させる
- CSS は当面 `assets/css/style.css` 1 ファイルで管理する
- JavaScript は当面 `assets/js/main.js` 1 ファイルで管理する
- 後の Cloudflare 公開を見据え、相対パスが破綻しにくい構成を維持する
